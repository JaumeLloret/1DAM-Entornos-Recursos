# E1 Contraste · extensión de tema local

Versión 1.0.0 · MIT. Contiene únicamente metadatos JSON, tema, licencia y manifiesto de empaquetado. No tiene `main`, scripts, dependencias ni conexión de red. Sirve para instalar, aplicar y desinstalar un módulo en VSCodium sin cuenta ni marketplace.

Usar `../tema-e1-1.0.0.vsix` mediante Extensions: Install from VSIX; seleccionar E1 Contraste; después Uninstall y comprobar ausencia. La instalación requiere que la política del centro permita paquetes locales. No desactivar controles globales si lo rechaza.

Se facilita también este contenido fuente para inspección; el alumnado no tiene que crear extensiones. El paquete tiene validación estructural; la instalación gráfica debe comprobarse en el entorno docente antes de publicar.
