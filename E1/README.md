# E1 · Del código al software

Archivos de apoyo al recorrido de E1 en AULES. Empieza por la guía de la unidad y realiza las actividades en el orden indicado allí.

## Proyecto inicial

Abre [el README del starter](starter-e1/README.md). Contiene los requisitos, los comandos de construcción, las salidas previstas y las instrucciones de IntelliJ y de la comparación con VSCodium.

1. Descarga y extrae el ZIP del repositorio desde **Code → Download ZIP**. No hace falta cuenta ni usar Git.
2. Dentro de la carpeta extraída, abre `E1/starter-e1` o su [`pom.xml`](starter-e1/pom.xml) en IntelliJ.
3. Conserva toda la carpeta: `src/`, `comparacion/`, `.vscode/tasks.json`, POM y README. La carpeta `.vscode` puede aparecer oculta en el explorador.
4. Sigue G03 de AULES con JDK 26 y Maven 3.9.16. El README explica cómo comprobar qué Java usa Maven. La primera construcción descarga herramientas de Maven.

El [ejemplo Java](starter-e1/src/main/java/aula/e1/Main.java) y la [muestra C](starter-e1/comparacion/saludo.c) son archivos suministrados para observar la construcción y ejecución. Para la comparación con C, sigue G07 y utiliza el compilador y el equipo que indique el docente.
