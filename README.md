# 1.º DAM · Entornos de Desarrollo · Recursos

Recursos de alumnado de Entornos de Desarrollo de 1.º DAM semipresencial: ejemplos, proyectos iniciales, plantillas y materiales para practicar las herramientas del módulo. Complemento de AULES.

La selección inicial corresponde a **E1 · Del código al software**.

- [Abrir los recursos y las instrucciones de E1](E1/README.md).

Para descargar la versión que estás consultando, utiliza **Code → Download ZIP** y extrae el archivo completo. En E1 no necesitas cuenta de GitHub, Git ni clonar el repositorio.

AULES contiene el recorrido de estudio, los ejemplos guiados, las consignas, la entrega, la evaluación y los canales de ayuda. Sus adjuntos siguen disponibles. Utiliza esta biblioteca para leer o descargar los archivos de trabajo cuando lo indique el curso.

El tema E1 conserva su [licencia MIT](E1/tema-e1/extension/LICENSE.txt). Los archivos se mantienen con sus avisos originales; esta selección no añade una licencia global al resto del material.
